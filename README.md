# Reaper Imbalance
A vanilla-esque Balatro mod that rebalances Jokers becausee I got bored. <br>

# Installation
Click on the green button on the top that says Code and download it as ZIP. <br>
Go to your Mods folder and extract the mod there.

# Changes
<b>Here are some example changes you MIGHT like:</b>

- Joker - reduced cost from $2 to $1
- Joker Stencil - from "adds x1 Mult" to "adds x2 Mult"
- Ceremonial Dagger - from "gains n amount of Mult" to "gains n amount of XMult"; added a max limit
- 8 Ball - from "1 in 4 chance" to "1 in 2 chance"; is now Uncommon
- (swapped even steven and odd todd order because why tf is steven at 39 and todd at 40 wtf)
- Runner - from "+15 Chips" to "+60 Chips"
- Green Joker - Discarding now resets Mult; from "+1 Mult" to "+2 Mult"
- Seance - reduced cost from $6 to $5; will now scale Xmult when playing Straight Flushes
- Obelisk - from "gains x0.2 Mult" to "gains x1 Mult"
- Campfire - from "x0.25" to "x0.5"; no longer resets after beating a Boss Blind
- Flower Pot - from "x3 Mult" to "gains +12 Mult"; now requires to play Four of a Kind
- Invisible Joker - from "2 rounds" to "3 rounds"; guarantees the copied Joker to be negative

<b>It's not just Jokers that got changed!</b>

- Chariot now allow 2 cards to be selected
- Lovers now allow 3 cards to be selected
- Tower now allows 2 cards to be selected
- Hieroglyph now gives -1 discard instead of -1 hand 
- Petroglyph now gives -1 hand instead of -1 discard
- Green Deck now gives $3 for each unused discard.
